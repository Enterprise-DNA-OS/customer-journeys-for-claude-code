# Views without an application front end

The weekly work is a review of steps, evidence, owners and decisions. Commands change those records; HTML snapshots show the week, priorities and the ordered journey. Documents carry the same evidence into a review meeting.

A visual canvas adds drag-and-drop editing, spatial storytelling, sticky-note workshops, media annotation and simultaneous collaboration. This build does not provide those. It has no mobile app or offline team synchronisation. Keep a visual workshop tool if those are essential. This is useful when the recurring work is operating the journey record after the workshop.

A custom version can add shared web views or another stack. Generated views have no access controls of their own; keep files private. Refresh after a change. /new-view adds a new read-only report and /customise changes the record or rule.
